# Jacquelin Anne Hellenberg Memorial Tribute Site

A beautiful memorial tribute website honoring Jacquelin Anne Hellenberg.

## Tech Stack

- **Framework**: React + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS + shadcn/ui components
- **Runtime**: Node.js 20

## Project Structure

```
src/
  sections/         # Individual page sections (Hero, Gallery, Family, etc.)
  components/ui/    # shadcn/ui component library
  hooks/            # React hooks
  lib/              # Utility functions
  index.css         # Global styles
  main.tsx          # App entry point
public/
  images/           # All photos and image assets
```

## Running the App

The app runs via the "Start application" workflow:
```
npm run dev
```
Served on port 5000.
